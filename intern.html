How my internship tracker works.

I stopped checking job sites. Once a week my AI goes through every posting on my list and tells me what closes first. Here's the setup, so you can copy it.

01

Start with a list

One row per role: the company, the role, the deadline, the link, and a status like researching, applied or closed. A spreadsheet works fine.

02

Once a week, it checks every posting

An AI agent opens every link still marked researching. If the posting is gone, it marks the role closed. If it's live, it writes down the date it checked.

03

It adds new roles that fit

It searches company career pages for new roles that match what you're looking for, and adds a few, only ones it confirmed are open that day.

04

It never guesses a deadline

It only writes a close date it actually saw on the posting. No date shown means no date written.

05

It leaves your edits alone

Anything you've changed yourself, like a role you applied to, stays exactly how you left it.

06

Then it sends one text

A single phone notification: what closes soonest, what closed, and what's new. That's the whole thing.

07

What it never does

It never applies, never signs up for anything, and never enters your information on any site. It reads and reports, and you do the applying.

08

What I run it on

  • An AI coding tool that can run a task on a schedule (I use Claude Code).
  • A spreadsheet or simple tracker it can read and update.
  • A push notification to your phone.
  • One instruction file that spells out the rules above.
